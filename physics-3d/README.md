# 经典物理实验 · 3D 实验室

用 [three.js](https://threejs.org/) 复现五个历史上最经典、又完全落在初高中知识范围内的物理实验。
场景里的运动、折射、磁场与浮力全部由真实公式**实时计算**，不是预录动画。

## 五个实验

| # | 实验 | 人物 · 年份 | 知识点 |
|---|------|------------|--------|
| 1 | 伽利略斜面实验 | 伽利略 · 1604 | 匀变速直线运动、`s = ½at²`、等时间隔位移比 1:3:5:7 |
| 2 | 托里拆利实验 | 托里拆利 · 1643 | 大气压强、`p = ρgh`、760 mmHg、真空 |
| 3 | 牛顿棱镜色散实验 | 牛顿 · 1666 | 折射定律、色散、判决性实验 |
| 4 | 奥斯特电流磁效应 | 奥斯特 · 1820 | `B = μ₀I/(2πr)`、安培定则、磁感线 |
| 5 | 阿基米德浮力实验 | 阿基米德 · 约公元前 245 | `F浮 = ρgV排`、沉浮条件、王冠之谜 |

每个实验都提供：可自由旋转/缩放的 3D 场景、可调参数、实时数值读数、原理推导与历史背景。

## 物理实现要点

- **伽利略斜面**：三种运动模型——理想滑块 `a = g·sinθ`、无滑滚动实心球 `a = 5/7·g·sinθ`、
  有摩擦滑块 `a = g(sinθ − μcosθ)`（tanθ < μ 时保持静止）。铃铛摆在 `s_k = L·k²/16` 处，
  滚过的时间间隔严格相等。
- **托里拆利**：液柱高度 `h = p/(ρg)`，大气压随海拔按国际标准大气模型
  `p = p₀(1 − 2.25577×10⁻⁵h)^5.25588` 变化；倾斜时竖直高度不变、沿管长度按 `1/cosθ` 增长；
  管长不足时管内充满、无真空。
- **牛顿棱镜**：逐界面求解的二维光线追踪器，含全反射判定；折射率由柯西公式
  `n(λ) = A + B/λ²` 给出（冕牌玻璃 / 火石玻璃 / 水三组系数）；56 条不同波长的光线独立追踪，
  落点实时绘制到光屏纹理上。光屏始终垂直于出射光束，距离可调，用来演示"光带长 ≈ 距离 × tanΔδ"。
- **奥斯特**：`B = μ₀I/(2πr)`，方向由 `Î × r` 给出；35 枚小磁针各自求解
  `tanα = B电流/B地磁`，因此离导线越远偏转越小。
- **阿基米德**：`F浮 = ρ液·g·V排`，测力计示数 `F示 = G − F浮`；漂浮时浸入比例 = `ρ物/ρ液`；
  沉底时浸没比例与液面高度互相牵制，用迭代求解。

## 本地运行

```bash
npm install
npm run dev      # 开发服务器
npm run build    # 产出到 dist/
npm run preview  # 预览构建结果
```

## 技术栈

three.js 0.185 · Vite 8 · 原生 ES 模块，无框架、无后端。
路由用 hash 实现，五个实验按需动态加载，可直接作为纯静态站点部署。

```
src/
├── main.js                 应用外壳与路由
├── core/
│   ├── Viewport.js         共用的渲染器 / 相机 / 轨道控制 / CSS2D 标签层
│   ├── ui.js               侧边栏控件工厂（滑块、分段选择、开关、读数）
│   └── physics.js          物理常量与工具（大气模型、柯西色散、波长转 RGB）
└── experiments/            五个实验各自独立的场景模块
```
